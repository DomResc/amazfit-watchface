# Watchface projects

[Essential](essential/README.md) is the first independent watchface: centered digital time, Italian/English date labels and AOD for Balance 2 XT.

[Matrix](matrix/README.md) adds retro dot-matrix time, activity metrics, analog seconds and a minimal AOD for Balance 2 XT. Its first build is locally validated, and the user confirmed a successful trial on Balance 2 XT. Detailed device checks remain pending.

Each project owns its manifest, lifecycle, layout and assets. Add shared code only when an actual second consumer requires it.

[Retro LCD](retro-lcd/README.md) adds a vintage smoked LCD design, activity instruments, alarm time, phone connection and Do Not Disturb indicators with minimal AOD. Physical-device validation is pending.
