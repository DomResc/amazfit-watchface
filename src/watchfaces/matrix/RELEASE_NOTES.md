Matrix 0.1.0 for Amazfit Balance 2 XT.

- Original retro dot-matrix digits with fixed 24-hour time and Italian/English date labels.
- Calories, last heart rate measurement, distance, battery and steps.
- Native analog battery and heart indicators, plus a two-digit seconds counter and seconds hand.
- Seconds dial aligned with the right edge of the minute digits.
- Minimal AOD with dimmer time and date.

Download the ZIP matching your deviceSource (`10486016`, `10486017` or `10486019`) and open it with Gadgetbridge.
The user confirmed a successful device trial on Balance 2 XT using the `10486017` build. Other variants are build-validated only. Detailed sensor, unit, AOD-transition and battery-impact checks remain unverified.

Tests, typecheck and package validation passed for this tagged revision. This release contains Matrix installation ZIPs only.
